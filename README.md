# Calculator

A simple interactive calculator built using **HTML, CSS, and JavaScript**. This project allows users to perform basic arithmetic operations through a graphical user interface.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Positive and negative number conversion (+/-)
- Backspace (⌫) to delete the last digit
- Decimal number input
- Interactive calculator buttons
- Error handling for division by zero

## Technologies Used

- **HTML5** – Structures the calculator interface.
- **CSS3** – Styles the calculator and its buttons using Flexbox.
- **JavaScript** – Handles user interactions and performs calculations.
